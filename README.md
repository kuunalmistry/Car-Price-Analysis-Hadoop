# Car Price Analysis Using the Hadoop Ecosystem

**Individual academic project — Large-Scale Data Storage (LSDS)**  
**Author:** Kuunal Mistry

An end-to-end academic exploration of large-scale vehicle-price data using the Hadoop ecosystem, followed by Python-based data visualization. This repository documents the work and experimental results; it is **not** a trained car-price prediction application.

![Project architecture](Dataset/Dashboards/project_architecture_professional.png)

## Project overview

The project explores distributed data storage and processing with **HDFS and MapReduce**, SQL-like analytics with **Apache Hive**, data transformations with **Apache Pig**, NoSQL storage with **Apache HBase**, and streaming exercises with **Apache Kafka**. Python scripts produce charts and dashboards for vehicle pricing trends.

## Repository contents

- `Dataset/car_price_prediction_.csv` — small source dataset.
- `Dataset/python files/` — Python scripts for dataset expansion, analysis and visualizations.
- `Dataset/Dashboards/` — generated dashboards, graphs and architecture image.
- `Individual Project ss/` — implementation evidence, organized by week and Kafka exercises.
- `Weekly Project Log/` — weekly submissions and the final report.
- `Project Instructions/` — original academic assignment instructions.

## Dataset preparation

The original submission included `Dataset/car_price_big.csv` (~160 MB), generated by repeating the smaller CSV using `expand_dataset.py`. It is intentionally excluded from this GitHub-ready version because it exceeds GitHub's standard per-file limit. To reproduce it:

```bash
python -m pip install -r requirements.txt
cd Dataset
python "python files/expand_dataset.py"
```

**Note:** Repeating records increases file size for storage/processing demonstrations; it does not create new independent observations.
